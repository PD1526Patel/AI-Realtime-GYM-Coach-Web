// TECHNICAL SPECIFICATIONS

How the Vision Pipeline Operates

High-performance machine learning workflow architected for sub-60ms edge inference without demanding GPU clusters.

PHASE 01 // INPUT

Frame Acquisition (OpenCV)

Captures real-time video stream at 30-60 FPS via WebRTC/OpenCV. Applies color space normalization (BGR to RGB) and spatial resizing.

PHASE 02 // SKELETON

MediaPipe 33-Keypoint Extraction

Deep convolutional neural network identifies 33 full-body landmarks in 3D coordinates (x, y, z) with confidence threshold filtering.

PHASE 03 // TRIGONOMETRY

Vector Angle Calculus

Computes Euclidean joint angles using the vector dot product law of cosines: θ = arccos((u · v) / (||u|| ||v||)), updating every frame.

PHASE 04 // LOGIC

Finite State Machine (FSM)

Tracks rep progression across discrete stages: Standing -> Eccentric Descent -> Target Parallel Peak -> Concentric Ascent -> Lockout.

PHASE 05 // SPEECH

Non-Blocking Audio Synthesis

Multi-threaded Pyttsx3 / Web Speech engine delivers instantaneous form corrections without hitching the video rendering pipeline.

PHASE 06 // STORAGE

Session Telemetry & History

Persists workout duration, rep counts, and biomechanical compliance scores to user database for longitudinal athletic progression.
